### Ownership model

MaxStarter **owns** files under `src/maxstarter/` and marked regions:

```ts
// MAXSTARTER:BEGIN id
...
// MAXSTARTER:END id
```

Everything else is yours. `apply-maxstarter` will not overwrite developer code outside those markers.

## Icons

Standard UI icons use `@expo/vector-icons` through the `AppIcon` component in `components/AppIcon.tsx`.

```tsx
import { AppIcon } from "../components";
import { colors } from "../src/maxstarter/theme";

<AppIcon name="home" size={24} color={colors.primary} />
```

Semantic names: `home`, `search`, `profile`, `settings`, `back`, `close`. Prefer `AppIcon` over importing the icon library in screens. Do not add SVG files for these standard icons.
